# 여행 계획 상세 조회

카테고리: 계획
사용자: 유저
Method: GET
URL: /api/v1/plans/{planId}
설명: 특정 여행 계획의 전체 경로와 정보를 조회합니다.
FE: 시작 전
BE: 시작 전
Auth: Yes
담당자: 이주형

### Request

| **key** | **설명** | **value 타입** | **옵션** | **Nullable** | **예시** |
| --- | --- | --- | --- | --- | --- |
| planId | 계획 ID | Integer | Path Variable | X | 255 |

**Query parameter**

### Response

| **key** | **설명** | **value 타입** | **옵션** | **Nullable** | **예시** |
| --- | --- | --- | --- | --- | --- |
| planId | 계획 ID | Integer |  | X | 255 |
| title | 제목 | String |  | X | "부산 먹방 여행" |
| startDate | 시작일 | String |  | X | "2025-06-01" |
| endDate | 종료일 | String |  | X | "2025-06-03" |
| courses | 여행 코스 | List |  | X | [...] |
| courses[].contentId | 관광지 ID | Integer |  | X | 12540 |
| courses[].title | 장소명 | String |  | X | "해운대" |
| courses[].latitude | 위도 | Double |  | X | 35.1587 |
| courses[].longitude | 경도 | Double |  | X | 129.1604 |
| courses[].day | 일차 | Integer |  | X | 1 |
| courses[].sequence | 순서 | Integer |  | X | 0 |

**Example**

```jsx
{
	"planId": 255,
  "title": "부산 먹방 여행",
  "startDate": "2025-06-01",
  "endDate": "2025-06-03",
  "courses": [
    {
      "contentId": 12540,
      "title": "해운대",
      "latitude": 35.1587,
      "longitude": 129.1604,
      "day": 1,
      "sequence": 0
    }
  ]
}
```

### Status

| status | response content |
| --- | --- |
| 200 | 조회 성공 |
| 401 | 인증 실패 |
| 403 | 권한 없음 |
| 404 | 존재하지 않음 |
