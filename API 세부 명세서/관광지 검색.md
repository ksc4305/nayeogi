# 관광지 검색

카테고리: 검색
사용자: 유저
Method: GET
URL: /api/v1/attractions/search
param: keyword, sidoCode, contentTypeId
설명: 키워드, 지역, 유형으로 관광지 정보를 검색합니다. (페이징 지원)
FE: 시작 전
BE: 시작 전
Auth: Yes
담당자: 이주형

### Request

**Query parameter**

| **key** | **설명** | **value 타입** | **옵션** | **Nullable** | **예시** |
| --- | --- | --- | --- | --- | --- |
| keyword | 검색어 | String |  | O | "국밥" |
| sidoCode | 지역 코드 | Integer |  | O | 1 (서울) |
| contentTypeId | 관광지 유형 | Integer |  | O | 12 (관광지) |
| page | 페이지 번호 | Integer | Default: 1 | O | 1 |
| size | 페이지 크기 | Integer | Default: 10 | O | 10 |

### Response

| **key** | **설명** | **value 타입** | **옵션** | **Nullable** | **예시** |
| --- | --- | --- | --- | --- | --- |
| count | 검색된 전체 개수 | Integer |  | X | 50 |
| hasNext | 다음 페이지 여부 | Boolean |  | X | true |
| attractions | 관광지 목록 | List |  | X | [...] |
| attractions[].contentId | 관광지 ID | Integer |  | X | 12345 |
| attractions[].title | 장소명 | String |  | X | "원조 국밥" |
| attractions[].addr1 | 주소 | String |  | O | "부산 해운대구..." |
| attractions[].firstImage | 썸네일 | String |  | O | "http://..." |
| attractions[].latitude | 위도 | Double |  | X | 35.1587 |
| attractions[].longitude | 경도 | Double |  | X | 129.1604 |

**Example**

```jsx
{
  "count": 50,
  "hasNext": true,
  "attractions": [
    {
      "contentId": 12345,
      "title": "원조 국밥",
      "addr1": "부산 해운대구...",
      "firstImage": "http://img...",
      "latitude": 35.1587,
      "longitude": 129.1604
    }
  ]
}
```

### Status

| status | response content |
| --- | --- |
| 200 | 검색 성공 |
| 400 | 잘못된 파라미터 (페이지 번호 음수 등) |
