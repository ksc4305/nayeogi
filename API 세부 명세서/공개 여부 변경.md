# 공개 여부 변경

카테고리: 스토리
사용자: 유저
Method: PATCH
URL: /api/v1/stories/{storyId}/visibility
설명: 스토리북의 공개 상태(Public/Private)를 수정합니다.
FE: 시작 전
BE: 시작 전
Auth: Yes
담당자: 강산천

### Request

| **key** | **설명** | **value 타입** | **옵션** | **Nullable** | **예시** |
| --- | --- | --- | --- | --- | --- |
| storyId | 스토리 ID | Integer | Path Variable | X | 501 |
| isPublic | 공개 여부 | Boolean |  | X | true |

**Query parameter**

### Response

| **key** | **설명** | **value 타입** | **옵션** | **Nullable** | **예시** |
| --- | --- | --- | --- | --- | --- |
| isPublic | 변경된 상태 | Boolean |  | X | true |

**Example**

```jsx
{
	"isPublic": true
}
```

### Status

| status | response content |
| --- | --- |
| 200 | 변경 성공 |
| 403 | 권한 없음 (내 글 아님) |
| 404 | 존재하지 않는 스토리 |
