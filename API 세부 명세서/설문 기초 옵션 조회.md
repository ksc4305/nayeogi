# 설문 기초 옵션 조회

카테고리: 추천
사용자: 유저
Method: GET
URL: /api/v1/recommendations/options
설명: 설문 화면(Q1~Q3)에 보여줄 선택지(지역, 동행, 테마)를 반환합니다.
FE: 시작 전
BE: 시작 전
Auth: Yes
담당자: 이주형

### Request

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |

**Query parameter**

### Response

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| sidos | 지역 목록 | List | DB 조회 | X | [...] |
| sidos[].code | 시도 코드 | Integer |  | X | 1 |
| sidos[].name | 지역명 | String |  | X | "서울” |
| companions | 동행 목록 | List | Enum | X | [...] |
| companions[].value | 전송값 | String |  | X | "FRIENDS” |
| companions[].label | 화면명 | String |  | X | "친구” |
| themes | 테마 목록 | List | Enum | X | [...] |
| themes[].value | 전송값 | String |  | X | "ACTIVITY” |
| themes[].label | 화면명 | String |  | X | "액티비티” |

**Example**

```jsx
{
  "sidos": [
    { "code": 1, "name": "서울" },
    { "code": 32, "name": "강원" }
  ],
  "companions": [
    { "value": "FRIENDS", "label": "친구" },
    { "value": "FAMILY", "label": "가족" }
  ],
  "themes": [
    { "value": "ACTIVITY", "label": "액티비티" },
    { "value": "HEALING", "label": "힐링" }
  ]
}
```

### Status

| status | response content |
| --- | --- |
| 200 | 조회 성공 |
| 500 | 서버 오류 |
