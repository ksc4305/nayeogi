# 테마별 상세 질문 조회

카테고리: 추천
사용자: 유저
Method: GET
URL: /api/v1/recommendations/questions/{theme}
설명: 선택한 테마(Q3)에 맞는 상세 질문지(Q4)를 반환합니다.
FE: 시작 전
BE: 시작 전
Auth: Yes
담당자: 이주형

### Request

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| theme | 테마 코드 | String | Path Variable | X | "ACTIVITY” |

**Query parameter**

/api/v1/recommendations/questions/{theme}

1. theme

### Response

| **key** | **설명** | **value 타입** | **옵션** | **Nullable** | **예시** |
| --- | --- | --- | --- | --- | --- |
| theme | 요청 테마 | String |  | X | "ACTIVITY" |
| items | 질문 목록 | List |  | X | [...] |
| items[].id | 질문 식별자 | String |  | X | "q_act_water" |
| items[].text | 질문 내용 | String |  | X | "물놀이를 좋아하시나요?" |

**Example**

```jsx
{
  "theme": "ACTIVITY",
  "items": [
    { "id": "q_act_water", "text": "물놀이를 좋아하시나요?" },
    { "id": "q_act_extreme", "text": "스릴 있는 활동을 즐기시나요?" }
  ]
}
```

### Status

| status | response content |
| --- | --- |
| 200 | 조회 성공 |
| 400 | 잘못된 테마 코드 |
