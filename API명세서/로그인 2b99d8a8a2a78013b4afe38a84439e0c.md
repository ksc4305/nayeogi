# 로그인

카테고리: 유저, 인증
사용자: 유저
Method: POST
URL: /api/v1/members/login
설명: 세션 로그인 (JSESSIONID 쿠키 발급)
FE: 시작 전
BE: 시작 전
Auth: No
담당자: 성환 박

### Request

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| email | 사용자 이메일 (ID) | String | format: email | X | "[ssafy@ssafy.com](mailto:ssafy@ssafy.com)" |
| password | 사용자 비밀번호 | String |  | X | “password1!” |

**Query parameter**

### Response

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| name | 사용자 이름 | String |  | X | "김싸피” |
| role | 사용자 권한 | String | USER, ADMIN | X | "USER” |

**Example**

```jsx
{
  "name": "김싸피",
  "role": "USER"
}
```

### Status

| status | response content |
| --- | --- |
| 200 | 로그인 성공 |
| 401 | 이메일 또는 비밀번호 불일치 |
