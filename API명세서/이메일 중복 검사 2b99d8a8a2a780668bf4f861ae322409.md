# 이메일 중복 검사

카테고리: 유저
사용자: 유저
Method: GET
URL: /api/v1/members/availability?email={email}
설명: 회원가입 시 이메일 중복 여부를 확인합니다.
FE: 시작 전
BE: 시작 전
Auth: No
담당자: 성환 박

### Request

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| email | 확인 할 이메일 | String | Query Param | X | "[ssafy@test.com](mailto:ssafy@test.com)" |

**Query parameter**

`/api/v1/members/availability?email=ssafy@test.com`

1. email (확인할 이메일)

### Response

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| isAvailable | 사용 가능 여부 | Boolean |  | X | true |

**Example**

```jsx
{
	"isAvailable": true
}
```

### Status

| status | response content |
| --- | --- |
| 200 | 조회 성공 (Body의 isAvailable 값 확인) |
| 400 | 이메일 형식 오류 (@ 누락 등) |
