# 회원 정보 수정

카테고리: 유저
사용자: 유저
Method: PUT
URL: /api/v1/members
설명: 비밀번호, 이름 등 정보를 수정합니다.
FE: 시작 전
BE: 시작 전
Auth: Yes
담당자: 성환 박

### Request

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| name | 변경할 이름 | String |  | O | "김싸피” |
| currentPassword | 현재 비밀번호 | String | 검증용 | O | “oldPassword!” |
| newPassword | 새 비밀번호 | String | min: 8 | O | "newPassword!” |

**Query parameter**

### Response

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| message | 결과 메시지 | String |  | X | "수정 성공” |
| name | 변경된 이름 | String |  | X | "김싸피” |

**Example**

```jsx
{
  "message": "수정 성공",
  "name": "김싸피"
}
```

### Status

| status | response content |
| --- | --- |
| 200 | 수정 성공 |
| 400 | 요청 오류 (새 비번은 있는데 현재 비번이 없음), 유효성 검사 실패 (비밀번호 규칙 등) |
| 401 | 인증 실패 (로그인 필요, 현재 비밀번호 불일치) |
