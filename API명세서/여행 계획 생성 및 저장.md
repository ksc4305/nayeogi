# 여행 계획 생성 및 저장

카테고리: 계획
사용자: 유저
Method: POST
URL: /api/v1/plans
설명: 작성된 계획(정보+경로)을 DB에 일괄 저장합니다.
FE: 시작 전
BE: 시작 전
Auth: Yes
담당자: 이주형

### Request

| **key** | **설명** | **value 타입** | **옵션** | **Nullable** | **예시** |
| --- | --- | --- | --- | --- | --- |
| title | 여행 계획 제목 | String |  | X | "부산 먹방 여행" |
| startDate | 시작일 | String | YYYY-MM-DD | X | "2025-06-01" |
| endDate | 종료일 | String | YYYY-MM-DD | X | "2025-06-03" |
| surveyId | 기반 설문 ID | Integer | (선택) | O | 501 |
| courses | 여행 코스 목록 | List<Object> |  | X | [...] |
| courses[].contentId | 관광지 ID | Integer |  | X | 12540 |
| courses[].day | 여행 일차 | Integer | 1, 2... | X | 1 |
| courses[].sequence | 순서 | Integer | 0, 1... | X | 0 |

**Query parameter**

### Response

| **key** | **설명** | **value 타입** | **옵션** | **Nullable** | **예시** |
| --- | --- | --- | --- | --- | --- |
| planId | 생성된 계획 ID | Integer |  | X | 255 |

**Example**

```jsx
{
	"planId": 255
}
```

### Status

| status | response content |
| --- | --- |
| 201 | 계획 저장 성공 |
| 400 | 입력값 오류 |
| 401 | 인증 실패 |
