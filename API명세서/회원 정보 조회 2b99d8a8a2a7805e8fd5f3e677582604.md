# 회원 정보 조회

카테고리: 유저
사용자: 유저
Method: GET
URL: /api/v1/members/me
설명: 로그인된 사용자(세션)의 정보를 조회합니다.
FE: 시작 전
BE: 시작 전
Auth: Yes
담당자: 성환 박

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |

### Response

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| memberId | 회원 고유 번호 (PK) | Integer |  | X | 101 |
| email | 사용자 이메일 (PK) | String | format: email | X | "[ssafy@ssafy.com](mailto:ssafy@ssafy.com)" |
| name | 사용자 이름 | String |  | X | "김싸피” |
| role | 사용자 권한 | String | USER, ADMIN | X | "USER” |
| joinDate | 가입일 | String | YYYY-MM-DD… | X | "2025-05-01 10:00:00” |

**Example**

```jsx
{
	"memberId": 101,
  "email": "ssafy@ssafy.com",
  "name": "김싸피",
  "role": "USER",
  "joinDate": "2025-05-01 10:00:00"
}
```

### Status

| status | response content |
| --- | --- |
| 200 | 조회 성공 |
| 401 | 인증 실패 (로그인 필요 OR DB에 회원 없음) |
