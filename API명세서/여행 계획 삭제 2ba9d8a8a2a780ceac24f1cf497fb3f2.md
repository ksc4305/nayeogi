# 여행 계획 삭제

카테고리: 계획
사용자: 유저
Method: DELETE
URL: /api/v1/plans/{planId}
설명: 특정 여행 계획을 삭제합니다.
FE: 시작 전
BE: 시작 전
Auth: Yes
담당자: 이주형

### Request

| **key** | **설명** | **value 타입** | **옵션** | **Nullable** | **예시** |
| --- | --- | --- | --- | --- | --- |
| planId | 계획 ID | Integer | Path Variable | X | 255 |

**Query parameter**

### Response

| **key** | **설명** | **value 타입** | **옵션** | **Nullable** | **예시** |
| --- | --- | --- | --- | --- | --- |
| message | 결과 메시지 | String |  | X | "삭제 성공" |

**Example**

```jsx

}
```

### Status

| status | response content |
| --- | --- |
| 200 | 삭제 성공 |
| 401 | 인증 실패 |
| 403 | 권한 없음 (내 계획 아님) |
| 404 | 존재하지 않음 |
