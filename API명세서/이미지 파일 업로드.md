# 이미지 파일 업로드

카테고리: 공통
사용자: 유저
Method: POST
URL: /api/v1/files/upload
설명: 사용자의 로컬 이미지 파일을 서버에 업로드하고 접근 가능한 URL을 반환합니다.
기타: multipart/form-data 필수
FE: 시작 전
BE: 시작 전
Auth: Yes
담당자: 강산천

### Request

| **key** | **설명** | **value 타입** | **옵션** | **Nullable** | **예시**  |
| --- | --- | --- | --- | --- | --- |
| files | 업로드할 이미지들 | List<MultipartFile> |  | X | (Binary Data Array) |

**Query parameter**

### Response

| **key** | **설명** | **value 타입** | **옵션** | **Nullable** | **예시** |
| --- | --- | --- | --- | --- | --- |
| imageUrls | 업로드된 URL 목록 | List<String> |  | X | `["http://.../a.jpg", "http://.../b.jpg"]` |

**Example**

```jsx
{
	"imageUrls": [
		"[http://domain.com/images/uuid_a.jpg](http://domain.com/images/uuid_a.jpg)",
		"[http://domain.com/images/uuid_b.jpg](http://domain.com/images/uuid_b.jpg)"
	]
}
```

### Status

| status | response content |
| --- | --- |
| 200 | 업로드 성공 |
| 400 | 파일 없음 또는 형식 오류 (이미지가 아님) |
| 413 | 파일 용량/개수 초과 |
| 500 | 서버 업로드 실패 (S3 오류 등) |
