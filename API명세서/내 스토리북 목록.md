# 내 스토리북 목록

카테고리: 스토리
사용자: 유저
Method: GET
URL: /api/v1/stories
설명: 내 스토리북 리스트를 조회합니다. (전체 또는 특정 계획별 필터링)
FE: 시작 전
BE: 시작 전
Auth: Yes
담당자: 강산천

### Request

| **key** | **설명** | **value 타입** | **옵션** | **Nullable** | **예시** |
| --- | --- | --- | --- | --- | --- |
| planId | 계획 ID 필터 | Integer | Query Param | O | 101 |

**Query parameter**

### Response

| **key** | **설명** | **value 타입** | **옵션** | **Nullable** | **예시** |
| --- | --- | --- | --- | --- | --- |
| stories | 스토리 목록 | List |  | X | [...] |
| stories[].storyId | 스토리 ID | Integer |  | X | 501 |
| stories[].planId | 원본 계획 ID | Integer |  | X | 101 |
| stories[].title | 제목 | String |  | X | "나의 부산 일기" |
| stories[].createdDate | 생성일 | String |  | X | "2025-06-05" |
| stories[].thumbnail | 썸네일 | String |  | O | "http://..." |

**Example**

```jsx
{
  "stories": [
    {
      "storyId": 501,
      "planId": 101,
      "title": "나의 부산 일기 (감성 Ver)",
      "createdDate": "2025-06-05",
      "thumbnail": "http://image.url/sample1.jpg"
    },
    {
      "storyId": 502,
      "planId": 101,
      "title": "우당탕탕 부산 모험 (개그 Ver)",
      "createdDate": "2025-06-06",
      "thumbnail": "http://image.url/sample2.jpg"
    }
  ]
}
```

### Status

| status | response content |
| --- | --- |
| 200 | 조회 성공 |
| 401 | 인증 실패 |
