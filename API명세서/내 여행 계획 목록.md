# 내 여행 계획 목록

카테고리: 계획
사용자: 유저
Method: GET
URL: /api/v1/plans
설명: 내가 작성한 여행 계획 리스트를 최신순으로 조회합니다.
FE: 시작 전
BE: 시작 전
Auth: Yes
담당자: 이주형

### Request

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |

**Query parameter**

### Response

| **key** | **설명** | **value 타입** | **옵션** | **Nullable** | **예시** |
| --- | --- | --- | --- | --- | --- |
| plans | 계획 목록 | List |  | X | [...] |
| plans[].planId | 계획 ID | Integer |  | X | 255 |
| plans[].title | 제목 | String |  | X | "부산 먹방 여행" |
| plans[].startDate | 시작일 | String |  | X | "2025-06-01" |
| plans[].endDate | 종료일 | String |  | X | "2025-06-03" |
| plans[].thumbnail | 대표 이미지 | String | (선택) | O | "http://..." |
| plans[].storyCount | 생성된 스토리 수 | Integer |  | X | 2 |

**Example**

```jsx
{
  "plans": [
    {
      "planId": 255,
      "title": "부산 먹방 여행",
      "startDate": "2025-06-01",
      "endDate": "2025-06-03",
      "thumbnail": "http://image.url/busan.jpg",
      "storyCount": 2
    },
    {
      "planId": 200,
      "title": "지난 제주도 여행",
      "startDate": "2024-12-01",
      "endDate": "2024-12-05",
      "thumbnail": null,
      "storyCount": 0
    }
  ]
}
```

### Status

| status | response content |
| --- | --- |
| 200 | 조회 성공 (계획이 없으면 빈 배열 `[]` 반환) |
| 401 | 인증 실패 (세션 만료) |
| 500 | 서버 내부 오류 |
