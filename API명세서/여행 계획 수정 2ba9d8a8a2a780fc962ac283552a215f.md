# 여행 계획 수정

카테고리: 계획
사용자: 유저
Method: PUT
URL: /api/v1/plans/{planId}
설명: 기존 계획의 경로를 수정하여 덮어씁니다.
FE: 시작 전
BE: 시작 전
Auth: Yes
담당자: 이주형

### Request

| **key** | **설명** | **value 타입** | **옵션** | **Nullable** | **예시** |
| --- | --- | --- | --- | --- | --- |
| planId | 계획 ID | Integer | Path Variable | X | 255 |
| title | 여행 계획 제목 | String |  | X | "부산 먹방 여행 (수정)" |
| startDate | 시작일 | String | YYYY-MM-DD | X | "2025-06-01" |
| endDate | 종료일 | String | YYYY-MM-DD | X | "2025-06-04" |
| courses | 여행 코스 목록 | List<Object> |  | X | [...] |
| courses[].contentId | 관광지 ID | Integer |  | X | 12540 |
| courses[].day | 여행 일차 | Integer |  | X | 1 |
| courses[].sequence | 순서 | Integer |  | X | 0 |

**Query parameter**

### Response

| **key** | **설명** | **value 타입** | **옵션** | **Nullable** | **예시** |
| --- | --- | --- | --- | --- | --- |
| message | 결과 메시지 | String |  | X | "수정 성공" |
| planId | 수정된 계획 ID | Integer |  | X | 255 |

**Example**

```jsx
{
	"message": "수정 성공",
  "planId": 255
}
```

### Status

| status | response content |
| --- | --- |
| 200 | 수정 성공 |
| 400 | 날짜 형식 오류 또는 데이터 부족 |
| 403 | 권한 없음 |
| 404 | 존재하지 않는 계획 ID |
