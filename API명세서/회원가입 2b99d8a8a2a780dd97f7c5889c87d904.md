# 회원가입

카테고리: 유저
사용자: 유저
Method: POST
URL: /api/v1/members/join
설명: 신규 회원 가입을 처리합니다.
기타: 비밀번호 암호화(BCrypt) 필수
FE: 시작 전
BE: 시작 전
Auth: No
담당자: 성환 박

### Request

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| email | 사용자 이메일 (ID) | String | format: email | X | "[ssafy@ssafy.com](mailto:ssafy@ssafy.com)" |
| password | 사용자 비밀번호 | String | min: 8 | X | “password1!” |
| name | 사용자 이름 | String |  | X | "김싸피” |

**Query parameter**

### Response

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| message | 결과 메시지 | String |  | X | "회원가입 성공” |

**Example**

```jsx
{
	"message": "회원가입 성공"
}
```

### Status

| status | response content |
| --- | --- |
| 201 | 회원가입 성공 (Created) |
| 400 | 입력값 오류 (유효성 검사 실패) |
| 409 | 이미 가입된 이메일 (Conflict) |
