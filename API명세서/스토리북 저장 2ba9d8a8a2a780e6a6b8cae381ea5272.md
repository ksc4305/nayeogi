# 스토리북 저장

카테고리: 스토리
사용자: 유저
Method: POST
URL: /api/v1/stories
설명: 완성된 스토리북을 생성(저장)합니다. (N차 창작 가능)
FE: 시작 전
BE: 시작 전
Auth: Yes
담당자: 강산천

### Request

```jsx
{
  "planId": 101,
  "title": "나의 부산 여행",
  "thumbnail": "http://domain.com/images/a_anime.jpg", // 사용자가 선택한 대표 사진
  "pages": [
    {
      "contentId": 12540,
      "imagePath": "http://domain.com/images/a_anime.jpg", // 변환된 사진일 수도 있음
      "finalText": "부산의 바다는..."
    }
  ]
}
```

| **key** | **설명** | **value 타입** | **옵션** | **Nullable** | **예시** |
| --- | --- | --- | --- | --- | --- |
| planId | 여행 계획 ID | Integer |  | X | 101 |
| title | 스토리북 제목 | String |  | X | "나의 부산 일기 (감성 Ver)" |
| thumbnail | 대표 이미지 URL | String | (User Pick) | O | "[http://img](http://img/)..." |
| pages | 페이지 목록 | List |  | X | [...] |
| pages[].contentId | 관광지 ID | Integer |  | X | 12540 |
| pages[].imagePath | 이미지 경로 | String | URL | O | "http://..." |
| pages[].finalText | 최종 텍스트 | String |  | X | "수정된 내용..." |

**Query parameter**

### Response

| **key** | **설명** | **value 타입** | **옵션** | **Nullable** | **예시** |
| --- | --- | --- | --- | --- | --- |
| storyId | 생성된 스토리 ID | Integer |  | X | 501 |

**Example**

```jsx
{
	"storyId": 501
}
```

### Status

| status | response content |
| --- | --- |
| 201 | 저장 성공 |
| 400 | 입력값 오류 |
| 401 | 인증 실패 |
