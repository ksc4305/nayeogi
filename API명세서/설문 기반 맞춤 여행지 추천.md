# 설문 기반 맞춤 여행지 추천

카테고리: 추천
사용자: 유저
Method: POST
URL: /api/v1/recommendations
설명: 설문 결과(벡터)를 분석하여 맞춤 관광지를 추천합니다.
FE: 시작 전
BE: 시작 전
Auth: Yes
담당자: 이주형

### Request

| **key** | **설명** | **value 타입** | **옵션** | **Nullable** | **예시** |
| --- | --- | --- | --- | --- | --- |
| sidoCodes | 시도 코드 목록 | List<Integer> |  | X | `[1, 32]` |
| companion | 동행 유형 | String | ENUM | X | `"FRIENDS"` |
| theme | 메인 테마 | String | ENUM | X | `"ACTIVITY"` |
| scores | 상세 취향 점수 | Map | 0~10 | X | `{"water": 8, "extreme": 9}` |
| page | 페이지 번호 | Integer | Default: 1 | O | `1` |
| size | 페이지 크기 | Integer | Default: 10 | O | `10` |

**Query parameter**

### Response

| **key** | **설명** | **value 타입** | **옵션** | **Nullable** | **예시** |
| --- | --- | --- | --- | --- | --- |
| count | 전체 결과 수 | Integer |  | X | 100 |
| hasNext | 다음 페이지 여부 | Boolean |  | X | true |
| attractions | 관광지 목록 | List |  | X | `[...]` |
| attractions[].contentId | 관광지 ID | Integer |  | X | 12540 |
| attractions[].title | 장소명 | String |  | X | "북한산 국립공원" |
| attractions[].addr1 | 주소 | String | **(New)** | O | "서울 강북구..." |
| attractions[].firstImage | 썸네일 | String |  | O | "http://..." |
| attractions[].latitude | 위도 | Double | **(New)** | X | 37.6606 |
| attractions[].longitude | 경도 | Double | **(New)** | X | 126.9935 |
| attractions[].matchScore | 적합도 | Double |  | O | 95.5 |

**Example**

```jsx
{
	"count": 100,
	"hasNext": true,
	"attractions": [
		{
		"contentId": 12540,
		"title": "북한산 국립공원",
		"addr1": "서울 강북구...",
		"firstImage": "[http://img](http://img/)...",
		"latitude": 37.6606,
		"longitude": 126.9935,
		"matchScore": 95.5
		}
	]
}
```

### Status

| status | response content |
| --- | --- |
| 200 | 분석 성공 |
| 400 | 입력값 오류 |
| 500 | 분석 서버 오류 |
