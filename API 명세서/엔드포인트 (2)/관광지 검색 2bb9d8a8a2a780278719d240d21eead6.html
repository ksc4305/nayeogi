Request

Query parameter

key설명value 타입옵션Nullable예시
keyword검색어StringO"국밥"
sidoCode지역 코드IntegerO1 (서울)
contentTypeId관광지 유형IntegerO12 (관광지)

Response

key설명value 타입옵션Nullable예시
count검색된 전체 개수IntegerX50
hasNext다음 페이지 여부BooleanXtrue
attractions관광지 목록ListX[...]
attractions[].contentId관광지 IDIntegerX12345
attractions[].title장소명StringX"원조 국밥"
attractions[].addr1주소StringO"부산 해운대구..."
attractions[].firstImage썸네일StringO"http://..."
attractions[].latitude위도DoubleX35.1587
attractions[].longitude경도DoubleX129.1604
