# [나의 여행 기록, 나여기] ✈️📖

> 사용자 성향 맞춤형 여행지 추천 및 여행 사진 스토리북 자동 제작 서비스

<br/>

## 📝 프로젝트 소개
**"어디로 떠나야 할지 모르겠나요?"**

이 프로젝트는 여행 전과 후의 고민을 모두 해결해 주는 **올인원 여행 플랫폼**입니다.
사용자의 취향과 성향을 설문조사 후 분석하여 **최적의 여행지를 추천**해줍니다.

<br/>

**"다녀온 여행 사진 정리가 귀찮으신가요?"**

사용자의 취향과 성향을 분석하여 **최적의 여행지를 추천**해주고, 여행 중 찍은 사진들을 업로드하면 자동으로
**나만의 여행 스토리북**을 만들어주어 소중한 추억을 간직할 수 있게 돕습니다.

<br/>

## 📌 주요 기능 및 요구사항 명세 (User Stories)

### 1. 회원 관리 기능
- [ ] **회원가입**: 이름, 아이디, 이메일, 비밀번호(확인), 핸드폰 번호, 주소 입력
- [ ] **로그인**: 아이디/비밀번호 인증 및 메인 화면 이동
- [ ] **회원 정보**: 프로필 상세 조회 및 정보 수정
- [ ] **계정 찾기**: 아이디 및 비밀번호 찾기 기능
- [ ] **회원 탈퇴**: 서비스 이용 종료 요청

### 2. 여행지 추천 기능 (Before Travel)
- [ ] **성향 분석**: 설문조사를 통해 사용자의 여행 스타일 데이터 수집
- [ ] **여행지 추천**: 분석 결과에 따른 맞춤형 여행지 목록 제공
- [ ] **코스 설계**:
    - 추천 여행지 중 시작 지점 선택
    - 다음 여행지까지의 허용 이동 거리 입력
    - 거리 내 재추천된 여행지 선택 과정을 반복하여 전체 코스 구성
- [ ] **코스 관리**: 완성된 여행 코스 저장, 불러오기, 수정, 삭제

### 3. AI 스토리북 생성 기능 (After Travel)
- [ ] **기본 설정**: 저장된 여행 코스 불러오기
- [ ] **데이터 입력**: 각 장소별 사진 업로드 및 경험 메모(Memo) 작성
- [ ] **AI 옵션 설정**:
    - **화풍 변환**: 원본 사진 유지 또는 AI 그림체로 변환 선택 (Image-to-Image)
    - **스토리 어조**: 스토리북의 분위기 선택 (예: 감성적, 유머러스 등)
- [ ] **제작 및 편집**:
    - AI가 생성한 스토리북 E-book 미리보기 (Text Generation)
    - 결과 불만족 시 옵션 수정 후 재생성 요청
- [ ] **저장 및 관리**: 완성된 스토리북 저장 및 공개/비공개 설정

### 4. 마이페이지 기능 (내 서재)
- [ ] **코스 보관함**: 내가 저장한 여행 코스 목록 확인 및 관리 (수정/삭제/재생성)
- [ ] **내 서재**: 내가 만든 스토리북 목록 확인
- [ ] **스토리북 관리**: 기존 스토리북 설정 수정 및 재생성

## 📜 Git 커밋 규칙 (Commit Convention)

협업을 위해 아래의 커밋 메시지 규칙을 준수합니다.

### 커밋 메시지 구조
`태그: 제목` (예: `Feat: 로그인 API 구현`)

### 태그 종류
| 태그 | 설명 |
| :--- | :--- |
| **Feat** | 새로운 기능 추가 |
| **Fix** | 버그 수정 |
| **Design** | CSS 등 사용자 UI 디자인 변경 |
| **!HOTFIX** | 급한 버그 수정 |
| **Style** | 코드 포맷 변경, 세미콜론 누락, 코드 수정이 없는 경우 |
| **Refactor** | 프로덕션 코드 리팩토링 (변수명 변경, 로직 개선 등) |
| **Comment** | 필요한 주석 추가 및 변경 |
| **Docs** | 문서 수정 (README.md 등) |
| **Test** | 테스트 코드, 리팩토링 테스트 코드 추가 |
| **Chore** | 빌드 업무 수정, 패키지 매니저 수정 |
| **Rename** | 파일 혹은 폴더명 수정하거나 옮기는 경우 |
| **Remove** | 파일 삭제 |
